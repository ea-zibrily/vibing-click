1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
In this session, we built and polished a full 2D clicker gameplay prototype from
the ground up:
- Core 2D interactive Square object with BoxCollider2D & squash-and-stretch feedback.
- ClickerManager handling Input System pointer clicks, raycast filtering, score tracking.
- TextMesh Pro UI Canvas with responsive CanvasScaler & dynamic score display.
- Right-side Arcanum Shop Panel with progressive upgrades (Multipliers, Particles, Rainbow Vibe).
- Continuous rotation animation with click spin impulse boost (SquareRotator).
- Visual overhaul with a Fantasy Dreamy Theme (floating sky islands, ambient fairy dust particles, 2D twilight lighting, celestial relic aura glow).

--------------------------------------------------------------------------------
2. SCRIPTS & COMPONENTS DEVELOPED
--------------------------------------------------------------------------------
- Assets/Project/Scripts/ClickerManager.cs
  * Supports Mouse, Touchscreen, and Pen via Pointer.current.
  * Guards against accidental clicks when clicking UI buttons.
  * Tracks Score, PointsPerClick, and provides TrySpendScore() for shop purchases.
  * Punch-scale bounce animation and optional audio hook.
  * Triggers particle burst and random color changes once unlocked.

- Assets/Project/Scripts/SquareRotator.cs
  * Configurable base rotation speed (default: 45 deg/s) & direction.
  * Momentary spin boost on click (+180 deg/s) decaying smoothly back to base speed.

- Assets/Project/Scripts/ShopManager.cs
  * Manages shop items and updates affordabilities when clicks change.
  * Dispatches upgrade effects (Multiplier boost, Particles unlock, Color unlock).

- Assets/Project/Scripts/ShopItem.cs
  * Controls individual item slots with progressive pricing or one-time unlock state.
